> [!IMPORTANT]
> **Notice:** Bot connection protocols have been updated to the latest WhatsApp Web version to prevent disconnections and ensure smooth logins.

---

### 1. What Was the Problem?
WhatsApp periodically updates its platform. If bot servers run outdated connection versions, bots can encounter issues such as failing to generate pairing codes, failing QR scans, or unexpected session disconnections.

---

### 2. What Was Fixed?
The WhatsApp connection version across all Zireku servers was updated to match the latest stable release from the WPPConnect ecosystem, with zero impact on user account data or existing bot configurations.

---

### 3. Effect on Users
* Login via pairing code (phone number) and QR code scanning work reliably without rejection by WhatsApp.
* Bots stay connected for longer periods without sudden drops.
* WhatsApp accounts connected to the bot platform remain secure.

---

### 4. Final Result
All server nodes (Gateway 1, 2, and 3) communicate using the modern WhatsApp protocol officially recognized by WhatsApp servers.
